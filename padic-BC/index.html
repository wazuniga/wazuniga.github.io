p-Adic Buice–Cowan theory: code, data and LaTeX source

Supplementary material for

  • W. A. Zúñiga-Galindo, p-Adic statistical field theory of fluctuation effects in hierarchical neural networks [PDF].
  • W. A. Zúñiga-Galindo, Hierarchical connectivity sets the upper critical dimension of neural avalanches [PDF].

Instructions for building, running and regenerating the figures are in the README.

Everything below (code and data) in one file: padic-BC_code_data.zip.

Code

  • code/sim/ — avalanche simulations: aval.c, avalp.c; drivers crit.py, production.py, extra.py, lp.py, lp_seeds.py; analysis analyze.py, lp_analyze.py, lp_test.py; plots plot_aval.py, plot_lp.py
  • code/smallworld/ — small-world tests: cover.c, levy.c, spread.c, graph.py, graph2.py, plot_sw.py
  • code/figures/ — analytic figures: make_figs.py, make_fig_regional.py

Data

  • data/sim/summary.json, summary_levy.json — critical points and exponents (Table II)
  • data/sim/res_*.npz — avalanche sizes, durations and spreading curves for each network
  • data/sim/lps_*.npy, lp_result.json — log-periodicity test
  • data/smallworld/ — spreading times (cov_*.txt, lv_*.txt) and graph statistics (graph.json, graph2.json, cover.json)

LaTeX source

  • latex/padic_BC_arxiv_v267.zip — source of the long paper (.tex, REVTeX files, figures)

The author used Claude (Anthropic) to help implement the numerical simulation code, as stated in the Methods of both papers.
